# v0.0.27 Quick Reference Card

## The Fix (TL;DR)

**What**: TLS renegotiation panic `sessionController.onEnterLoadSessionCheck failed: session is set and locked`  
**Why**: v0.0.24 fix was a no-op (ApplyPreset overwrites config value)  
**Solution**: Wrap GetClientHelloSpec to patch spec-level RenegotiationInfoExtension  
**Status**: Deployed in v0.0.27 (commit aa819b5)

## Failure Response (If Panic Occurs)

1. **Note the time**
2. **Revert immediately**:
   ```bash
   go get github.com/sadewadee/foxhound@v0.0.26
   go mod tidy
   docker build -t foxhound-serp-scraper:v0.0.26-niche .
   docker compose -f docker-compose.yaml up -d
   ```
3. **Collect logs**:
   ```bash
   docker logs enrich > panic_logs.txt
   docker ps -a > containers.txt
   ```
4. **Post on GitHub issue #43** with:
   - Exact time panic occurred
   - Full panic stack from logs
   - Load profile (N workers, job rate, duration)
   - Exact foxhound version in binary (not just go.mod)
